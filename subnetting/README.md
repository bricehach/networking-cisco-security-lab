# Subnetting & adressage IP

Cette section regroupe les travaux sur IPv4, CIDR, masques, calcul de sous-réseaux, plages d'hôtes, broadcast et plans d'adressage.

## Objectif cybersécurité

Comprendre précisément les périmètres réseau, les segments, les flux possibles et les erreurs de configuration liées à l'adressage.
