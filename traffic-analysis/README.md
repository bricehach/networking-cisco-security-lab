# Analyse de trafic

Cette section est consacrée à l'observation et à l'interprétation des flux réseau, notamment avec Wireshark.

## Sujets

- captures de paquets ;
- filtres d'affichage ;
- ARP, ICMP, TCP, UDP, DNS, HTTP/HTTPS ;
- établissement de connexions ;
- erreurs et retransmissions ;
- lecture d'un échange réseau ;
- identification d'un comportement inhabituel dans un laboratoire autorisé.

L'objectif est de relier la théorie réseau aux traces réellement visibles lors d'une investigation ou d'une analyse SOC.
