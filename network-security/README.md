# Sécurité réseau

Cette section relie les fondamentaux réseau à la cybersécurité : segmentation, filtrage, règles, pare-feu, NAT, pfSense et principes de réduction des communications inutiles.

## Objectif

Comprendre comment l'architecture réseau peut limiter l'exposition, contrôler les flux et fournir des points d'observation utiles au SOC.
