# Révisions et examens

Cette section rassemble des supports de révision originaux pour consolider les notions réseau et Cisco étudiées dans le dépôt.

## Contenu prévu

- fiches de synthèse par grande matière ;
- exercices récapitulatifs construits à partir des laboratoires ;
- corrigés expliqués, avec les commandes de vérification ;
- listes de contrôle pour préparer une évaluation pratique.

## Méthode

Chaque exercice doit préciser les prérequis, les objectifs, les résultats attendus et les preuves de validation. Les corrigés expliquent le raisonnement et les erreurs possibles au lieu de présenter uniquement une configuration finale.

Les consignes, questions et documents d’évaluation fournis par un établissement ne seront pas reproduits. Les supports publiés ici doivent être rédigés sous une forme pédagogique originale et ne contenir aucune donnée personnelle ou information propre à un examen.

## État

Les supports seront ajoutés après vérification technique et réécriture des notes ou exercices concernés.
