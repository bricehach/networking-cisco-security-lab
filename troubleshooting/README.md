# Troubleshooting réseau

Cette section documente une méthode de diagnostic structurée : état physique, interfaces, adressage, VLAN, trunks, routage, tables, tests ICMP et analyse des écarts entre comportement attendu et observé.

## Principe

Ne pas corriger au hasard : vérifier couche par couche, formuler une hypothèse, tester, puis valider.
