# VLAN & Trunking

Cette section regroupe les travaux sur les VLAN, les ports access, les trunks 802.1Q et la segmentation logique d'un réseau commuté.

## Objectif cybersécurité

Comprendre comment isoler des groupes de machines, limiter les domaines de broadcast et préparer une segmentation cohérente avant filtrage et contrôle des flux.
